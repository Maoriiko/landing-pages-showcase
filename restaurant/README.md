# Taverna Soleil - Mediterranean Kitchen

![Landing page screenshot](screenshot.png)

A responsive static landing page for Taverna Soleil mediterranean kitchen, centered around the hero message: "Where the Mediterranean Sings."

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
