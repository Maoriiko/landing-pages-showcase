# Northstar Sails - Sailing Charter

![Landing page screenshot](screenshot.png)

A breezy sailing charter page for sunset cruises, island routes, lessons, and private celebrations.

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
