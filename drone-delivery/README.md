# AeroDrop - Drone Delivery

![Landing page screenshot](screenshot.png)

A futuristic drone delivery page for medical, retail, and campus logistics with live route previews.

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
