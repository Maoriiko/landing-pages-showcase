# Airwave - Podcasts Worth Hearing

![Landing page screenshot](screenshot.png)

A responsive static landing page for Airwave podcasts worth hearing, centered around the hero message: "Podcasts that make your commute count."

## Quick Start

Open `index.html` in your browser.

