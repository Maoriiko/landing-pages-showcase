# SousLink - Smart Kitchen

![Landing page screenshot](screenshot.png)

A refined smart kitchen page for connected appliances, guided recipes, pantry tracking, and meal timing.

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
