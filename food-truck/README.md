# Rolling Saffron - Street Kitchen

![Landing page screenshot](screenshot.png)

A vivid food truck page for live location, daily bowls, catering, and limited-run specials.

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
