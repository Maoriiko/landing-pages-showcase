# Flour & Ember - Wood Fired Bakery

![Landing page screenshot](screenshot.png)

A warm bakery landing page for sourdough drops, pastry shelves, and neighborhood pickup.

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
