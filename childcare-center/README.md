# Little Lantern - Childcare Center

![Landing page screenshot](screenshot.png)

A bright childcare landing page for families comparing classrooms, schedules, and early learning programs.

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
