# MediSwift - Online Pharmacy

![Landing page screenshot](screenshot.png)

A responsive static landing page for MediSwift online pharmacy, centered around the hero message: "Your pharmacy, at your door."

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
