# Crux Yard - Indoor Climbing

![Landing page screenshot](screenshot.png)

A bold climbing gym page for route setting, memberships, training boards, and community nights.

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
