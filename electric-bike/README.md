# Volt Lane - Electric Bikes

![Landing page screenshot](screenshot.png)

A sleek e-bike page for commuter models, range comparison, financing, and service plans.

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```

- Removable battery
- Torque sensing motor
- Integrated lights
- Theft-safe app lock
