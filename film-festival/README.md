# Frame Harbor - Film Festival

![Landing page screenshot](screenshot.png)

A cinematic film festival page for passes, premieres, short blocks, and director conversations.

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
