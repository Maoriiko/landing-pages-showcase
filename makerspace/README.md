# Forge Commons - Makerspace

![Landing page screenshot](screenshot.png)

A practical makerspace page for tool access, classes, fabrication bays, and member projects.

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
