# Glass Skin Clinic - Skincare Clinic

![Landing page screenshot](screenshot.png)

A modern skincare clinic page for consultations, treatment plans, facial programs, and progress tracking.

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
