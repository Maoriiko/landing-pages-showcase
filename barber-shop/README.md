# Northcut - Modern Barber Lounge

![Landing page screenshot](screenshot.png)

A crisp barber shop page for appointments, memberships, beard work, and lounge-style service.

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
