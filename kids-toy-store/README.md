# Wonderbox - Educational Toys for Kids

![Landing page screenshot](screenshot.png)

A responsive static landing page for Wonderbox educational toys for kids, centered around the hero message: "Toys that teach while they play!"

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
