# BrightMove - Moving Company

![Landing page screenshot](screenshot.png)

A friendly moving company page for quotes, packing support, local moves, and long-distance planning.

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
