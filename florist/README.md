# Bloom Relay - Floral Studio

![Landing page screenshot](screenshot.png)

A delicate florist page for subscriptions, event florals, same-day bouquets, and seasonal stems.

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
