# landing-pages-showcase

A collection of responsive static landing page templates with source files, screenshots, and README documentation.

## Quick Start

Open any landing page by opening its `index.html` file in a browser.

```bash
# Example on Windows PowerShell
cd coffee-shop
start index.html
```

Each landing page is a standalone static site, so no build step or package installation is required.

## Project Structure

```text
landing-pages-showcase/
|-- coffee-shop/
|   |-- index.html
|   |-- style.css
|   |-- script.js
|   |-- screenshot.png
|   `-- README.md
|-- tech-startup/
|   `-- ...
`-- README.md
```

Every landing-page folder contains:

- `index.html` - Page markup and structure
- `style.css` - Custom styles and responsive layout
- `script.js` - Page interactions and dynamic details
- `screenshot.png` - Desktop hero screenshot
- `README.md` - Page-specific documentation
