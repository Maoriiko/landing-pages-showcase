# Needle & Dust - Vintage Records

![Landing page screenshot](screenshot.png)

A nostalgic record shop page for crate drops, listening booths, trade-ins, and collector alerts.

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
