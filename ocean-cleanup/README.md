# TideTurn - Ocean Cleanup

![Landing page screenshot](screenshot.png)

A mission-led ocean cleanup page for volunteer drives, intercept systems, impact metrics, and donations.

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
