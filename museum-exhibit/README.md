# Echo Hall - Museum Exhibit

![Landing page screenshot](screenshot.png)

An elegant museum exhibit page for featured objects, timed entry, guided tours, and curator notes.

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
