# SpokeForge - Bicycle Repair

![Landing page screenshot](screenshot.png)

A kinetic bike repair landing page for tuneups, wheel builds, diagnostics, and same-day service.

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
