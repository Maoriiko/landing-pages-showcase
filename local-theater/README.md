# The Lantern Stage - Local Theater

![Landing page screenshot](screenshot.png)

An intimate local theater page for season tickets, community productions, workshops, and donor nights.

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
