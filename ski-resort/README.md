# Alpenglow Ridge - Ski Resort

![Landing page screenshot](screenshot.png)

A crisp ski resort page for lodging, lift passes, snow reports, and slope-side dining.

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
