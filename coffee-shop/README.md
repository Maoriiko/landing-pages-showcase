# Ember & Grind - Artisan Coffee

![Landing page screenshot](screenshot.png)

A responsive static landing page for Ember & Grind artisan coffee, centered around the hero message: "Where Every Sip Tells A Story."

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
