# Ink Dock - Print Studio

![Landing page screenshot](screenshot.png)

A graphic printing studio page for risograph runs, posters, packaging, and small-batch production.

## Quick Start

Open `index.html` in your browser.

```bash
# Windows PowerShell
start index.html
```
